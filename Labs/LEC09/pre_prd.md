애니메이션 뷰어 기획 초안.

1. pico2d 이용
2. 파이썬 이용
3. 단일 파일로 생성 이름은 animation_viewr.py
4. 스프라이트 시트는 sonic-sprite.png 이용

기능
스프라이트 시트에 담겨있는 모든 애니메이션 재생
한 동작에 애니메이션을 5번 반복 재생 후 1초 정지 후 다음 애니메이션 재생
전체 애니메이션 재생이 끝나면 다시 무한 반복함.
이미지의 크기는 화면에서 잘 보이도록 확대한다. 

구현 절차 
한 번에 모든 코드를 작성하지 않고 단계별로 작성해 최소한 20번 이상의 커밋이 되도록 해야한다.
