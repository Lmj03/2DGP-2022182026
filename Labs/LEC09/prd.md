# LEC09 애니메이션 뷰어 PRD

## 1. 문서 정보

- 제품명: Sonic Sprite Animation Viewer
- 대상 경로: `Labs/LEC09`
- 실행 파일: `animation_viewr.py`
- 입력 이미지: `sonic-sprite.png`
- 기술 스택: Python, `pico2d`
- 문서 상태: 개발 기준 문서

## 2. 제품 개요

`sonic-sprite.png`에 포함된 Sonic 캐릭터의 애니메이션 프레임을 화면에 확대해 보여주는 학습용 애니메이션 뷰어다. 사용자의 입력 없이 등록된 동작을 순서대로 재생하며, 전체 동작이 끝나면 처음부터 다시 재생한다.

이 프로그램의 목적은 게임 플레이를 구현하는 것이 아니라 스프라이트 시트에서 프레임을 잘라내고, 일정한 재생 규칙에 따라 애니메이션을 연결하는 과정을 확인하는 것이다.

## 3. 목표와 범위

### 3.1 목표

1. `pico2d`로 창을 열고 스프라이트 시트를 불러온다.
2. 스프라이트 시트에 포함된 모든 애니메이션 동작을 빠짐없이 재생한다.
3. 각 동작을 5회 반복한 뒤 1초 정지하고 다음 동작으로 넘어간다.
4. 마지막 동작까지 재생하면 첫 동작으로 돌아가 무한 반복한다.
5. 캐릭터가 화면에서 식별되도록 원본보다 크게 출력한다.
6. 이동이 포함된 동작은 화면 안에서 실제 위치가 변하는 모습을 보여준다.

### 3.2 범위에 포함하지 않는 기능

- 키보드나 마우스로 동작을 선택하는 기능
- 재생·일시정지·배속 조절 UI
- 캐릭터 이동, 충돌, 게임 규칙
- 사운드와 배경 음악
- 여러 스프라이트 시트를 동시에 표시하는 기능
- 별도 설정 파일 또는 외부 애니메이션 데이터베이스

## 4. 사용자 시나리오

1. 사용자가 `Labs/LEC09`에서 `python animation_viewr.py`를 실행한다.
2. 프로그램은 `sonic-sprite.png`를 읽고 애니메이션 창을 연다.
3. 첫 번째 동작의 프레임이 정해진 속도로 재생된다.
4. 첫 번째 동작이 5회 반복되면 화면을 유지한 채 1초 대기한다.
5. 같은 방식으로 모든 동작을 순서대로 재생한다.
6. 마지막 동작의 대기가 끝나면 다시 첫 번째 동작부터 재생한다.
7. 사용자가 창을 닫으면 프로그램이 정상적으로 종료된다.

## 5. 기능 요구사항

### FR-01. 창 초기화

- `pico2d.open_canvas()`로 실행 창을 연다.
- 창 크기는 가로 1200픽셀, 세로 800픽셀의 고정 크기로 설정한다.
- 기본 출력 위치는 화면 중앙으로 한다.
- 창과 이미지 리소스는 프로그램 종료 시 정상적으로 닫고 해제한다.

### FR-02. 이미지 로드

- 실행 위치에 관계없이 `Labs/LEC09/sonic-sprite.png`를 찾을 수 있도록 이미지 경로를 구성한다.
- 이미지가 없거나 로드할 수 없으면 추적 가능한 오류 메시지를 출력하고 비정상적인 무한 루프에 진입하지 않는다.
- 원본 스프라이트 시트 전체를 화면에 출력하지 않고, 프레임 좌표로 필요한 영역만 잘라낸다.

### FR-03. 애니메이션 데이터 관리

- 각 동작은 다음 정보를 갖는 데이터 단위로 관리한다.
  - 동작 이름
  - 프레임 목록
  - 각 프레임의 원본 좌표와 크기 `(x, y, width, height)`
  - 프레임 간 지연 시간
  - 이동 동작 여부와 이동 시작·종료 위치
- 프레임 좌표는 재생 로직과 분리해 한 곳에서 수정할 수 있어야 한다.
- `sonic-sprite.png`에 실제로 존재하는 프레임만 등록한다.
- 프레임 목록의 순서는 시트의 동작 흐름과 자연스러운 재생 방향을 따른다.

### FR-04. 프레임 재생

- 현재 동작의 프레임을 순서대로 한 번씩 출력한다.
- 프레임 출력 순서는 등록된 프레임 목록의 순서를 따른다.
- 각 프레임 출력 사이에는 해당 동작의 지연 시간을 적용한다.
- 매 프레임마다 캔버스를 갱신해 잔상이 남지 않도록 한다.
- 서로 다른 원본 프레임 크기로 인해 캐릭터가 화면 안에서 불필요하게 흔들리지 않도록 출력 기준점을 일관되게 유지한다.
- 이동 동작은 프레임 재생과 함께 캐릭터의 화면 좌표를 갱신한다.

### FR-05. 이동 동작 재생

- 달리기, 걷기, 구르기, 미끄러지기를 이동 동작으로 취급한다.
- 이동 동작은 한 동작의 5회 반복 구간 동안 화면 왼쪽에서 오른쪽으로 이동한다.
- 이동 시작 위치와 종료 위치는 캐릭터가 창 밖으로 잘리지 않도록 설정한다.
- 이동 동작이 아닌 동작은 기존처럼 화면 중앙에서 재생한다.
- 이동 위치 계산은 프레임 재생 속도와 분리하되, 프레임마다 한 번 갱신한다.
- 다음 동작으로 넘어갈 때 이동 동작의 시작 위치를 초기화한다.

### FR-06. 반복 및 동작 전환

- 한 동작은 정확히 5회 반복한다.
- 5회 반복 직후 1초 동안 다음 동작으로 전환하지 않는다.
- 대기 시간이 끝나면 다음 동작을 시작한다.
- 마지막 동작 뒤에도 동일한 1초 대기를 적용한 뒤 첫 동작으로 돌아간다.
- 전체 재생은 프로그램이 종료될 때까지 반복한다.

### FR-07. 종료 처리

- 창 닫기 이벤트가 발생하면 반복문을 탈출한다.
- 종료 시 `close_canvas()`가 호출되도록 한다.
- 정상 종료 후 프레임 재생 루프가 남아 있지 않아야 한다.

## 6. 재생 규칙

동작 하나의 재생 순서는 다음과 같다.

```text
동작 선택
  -> 프레임 목록을 1회 재생
  -> 위 과정을 총 5회 반복
  -> 1초 정지
  -> 다음 동작 선택
```

전체 동작은 다음과 같이 순환한다.

```text
동작 1 -> 동작 2 -> ... -> 마지막 동작 -> 1초 정지 -> 동작 1
```

이동 동작은 다음과 같이 재생한다.

```text
이동 시작 위치 -> 프레임 재생과 함께 오른쪽 이동 -> 이동 종료 위치
```

프레임 지연 시간은 동작의 특성에 맞춰 설정하되, 처음 구현에서는 코드에 명시적인 상수 또는 동작별 값으로 관리한다. 지연 시간 변경이 반복 횟수나 동작 전환 규칙을 바꾸어서는 안 된다.

## 7. 화면 및 출력 요구사항

- 창 배경과 캐릭터가 명확히 구분되어야 한다.
- 캐릭터는 화면 중앙에 배치한다.
- 원본 프레임의 투명 배경이 유지되어야 한다.
- 캐릭터가 창 밖으로 잘리지 않도록 확대 배율과 창 크기를 함께 조정한다.
- 프레임 크기가 달라도 캐릭터의 발 위치 또는 캐릭터 중심이 크게 이동하지 않아야 한다.
- 이동 동작은 1200x800 화면 안에서 왼쪽부터 오른쪽까지 이동하는 모습을 확인할 수 있어야 한다.
- 이동 동작이 아닌 동작은 화면 중앙에 유지되어야 한다.
- 별도 HUD나 설명 텍스트는 필수 범위가 아니다.

## 8. 구현 구조

파일은 하나만 사용한다.

```text
Labs/LEC09/

├─ sonic-sprite.png
└─ prd.md
```

권장 코드 구성은 다음과 같다.

1. `pico2d` 및 표준 라이브러리 import
2. 이미지 경로와 화면 설정 상수
3. 동작별 프레임 좌표 데이터
4. 이미지 로드 및 창 초기화
5. 단일 동작을 재생하는 함수
6. 전체 동작을 순환 재생하는 메인 루프
7. 창 종료 및 리소스 정리

프레임 좌표 이름과 함수 이름은 Python의 일반적인 `snake_case` 표기법을 사용한다. 단일 파일 요구사항을 지키기 위해 별도 모듈이나 클래스 파일을 추가하지 않는다.

## 9. 오류 및 경계 조건

- 이미지 파일이 없을 때: 경로와 파일명을 포함한 오류를 출력하고 종료한다.
- 프레임 좌표가 이미지 영역을 벗어날 때: 해당 좌표를 수정하고, 잘못된 프레임을 조용히 건너뛰지 않는다.
- 프레임 목록이 비어 있을 때: 해당 동작을 재생하지 않고 즉시 오류를 알린다.
- 창이 닫힐 때: 다음 프레임을 계속 그리지 않고 즉시 종료 절차로 이동한다.
- 이미지 프레임의 크기가 서로 다를 때: 화면 중앙 또는 기준선 정렬 규칙을 유지한다.
- 이동 동작의 위치가 화면 경계를 벗어나지 않도록 시작·종료 위치를 검증한다.
